- **Función:** comprobar presencia de `TOKEN_4GEEKS`; efectuar únicamente GET a `/v1/admissions/user/me` con `Authorization: Token …`; descartar el cuerpo y emitir solo estado/código o categoría de error. No hace login ni expone token/cabeceras/respuesta.
- **Prueba real:** ejecutada en este entorno el 2026-11-20. `TOKEN_4GEEKS` estaba configurada y el GET `user_me` devolvió HTTP 200. Resultado: el servidor aceptó la autenticación para este endpoint en el momento de la prueba. El valor del token, cabeceras y cuerpo de respuesta no se mostraron ni registraron.
- **Validación de skill:** `quick_validate.py` informó `Skill is valid!`; `node --check` terminó sin errores.
- **Estado:** implementada, validada y operativa para comprobar acceso a `GET /v1/admissions/user/me`; esto no garantiza otros permisos ni vigencia futura.
